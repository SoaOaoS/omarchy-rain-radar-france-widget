# Map sources

The country outlines in `MapData.js` come from [Natural Earth 1:10m Admin 0
countries](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/),
via the [Natural Earth vector
repository](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson)
(fetched 2026-10-12). Natural Earth data is [public
domain](https://www.naturalearthdata.com/about/terms-of-use/).
`MapData.js` is generated by `tools/build-map-data.cjs` — don't edit it by
hand.

- **France** (`ADM0_A3 == 'FRA'`): the exterior rings that reach the map
  (the mainland, Corsica and the coastal islands; Natural Earth's France also
  holds the overseas territories, which are left out), simplified with
  Douglas–Peucker at 0.008° (~800 m, about a third of a pixel at the panel's
  normal scale) to ~1,350 points, rounded to 4 decimal places. Interior holes
  (lakes) are not included.
- **Neighbours** (United Kingdom, Spain, Italy, Switzerland, Germany, Belgium,
  the Netherlands, Luxembourg, Andorra, Austria, Jersey, Guernsey): context
  only. Exterior rings are clipped to the map domain plus a 0.3° margin (so
  the artificial clip edges fall outside anything drawn) and simplified the
  same way. All countries come from the same source so the shared borders
  match. Monaco is too small to draw.
- **Labels** are placed by hand on land; `tests/maprange.test.cjs` checks
  each one really falls inside its own country and inside the view.

## Domain and projection

The data covers `MapModel.bounds` (9.5°W–10.5°E, 41–52°N); the panel shows
`MapModel.view` (8.5°W–10°E, 41.2–51.3°N). `MapModel.js` draws it in a
cosine-scaled equirectangular projection (longitude scaled by cos 46.5°,
mainland France's mid-latitude) so shapes read correctly rather than looking
unnaturally wide. `helpers/radar-convert.py` places the radar tiles (Web
Mercator) on this exact same projection before they are composited, so radar
and coastlines line up without any runtime reprojection.

The bar icon's peak rain rate is taken over `MapModel.franceBounds` (5.2°W–
9.6°E, 41.3–51.1°N), a sub-rectangle of the map.

## Radar

[RainViewer](https://www.rainviewer.com/api.html)'s public radar composite:
four 512 px tiles at zoom 5 per frame (columns 15–16, rows 10–11), one frame
every 10 minutes, no API key. The colour of each pixel is turned back into
dBZ with RainViewer's published "Universal Blue" [colour
table](https://www.rainviewer.com/files/rainviewer_api_colors_table.csv)
(copied into `helpers/radar-convert.py`).

## What this map is and isn't

A regional overview for the radar/forecast overlay, not a precise
administrative boundary and not a radar coverage map: far out over the
Atlantic no radar measures anything, and the frame renders as empty there.

## Town search

The panel's town search looks in `Towns.js`: the 34,746 communes of mainland
France and Corsica with their centre, population and department, from the
State's [API Découpage administratif](https://geo.api.gouv.fr/decoupage-administratif)
(INSEE and IGN data) with one request, built by `tools/build-towns.cjs` (the
command is in that file).
